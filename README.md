This project was made for fun, a part of the code was inspired from youtube, github and different sources. The code aims to encrypt the message the user provides, then decrpyt it.
To encrpyt a message, simply enter your message into the provided area! As an output, you will receive the encrypted message. To decrypt it, enter the encrypted message into the provided area again. You'll receive the decoded message.
